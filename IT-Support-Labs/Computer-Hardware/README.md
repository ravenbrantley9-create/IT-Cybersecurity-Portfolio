## 🧠 Topics Learned

### Binary & Data Representation

- Binary uses 0s and 1s to represent information
- A bit is a single binary digit
- 8 bits make one byte
- Binary values can be converted to decimal values
- Computers use binary to process and store data

### CPU & Computer Architecture

- The CPU processes instructions
- Registers provide very fast temporary storage inside the CPU
- CPU cache helps the processor access frequently needed data quickly
- The data bus transfers information between computer components
- The address bus helps identify where data should be read from or written to
- RAM temporarily stores information being actively used by the computer

### Logic Gates

Studied basic digital logic including:

- AND
- OR
- NOT
- XOR
- NAND
- XNOR
- Truth tables

Logic gates use binary inputs and outputs and form the foundation of how computers perform logical operations.

### RAM & Memory

- Identifying RAM modules
- Understanding the purpose of system memory
- Understanding RAM slots
- Testing RAM modules individually during troubleshooting
- Recognizing that RAM problems can prevent a computer from completing POST
